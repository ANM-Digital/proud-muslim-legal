Proud Muslim Legal Centre: 11-language overlay

Back up your proud-muslim-legal website folder first. When upgrading an existing 22-language installation, move the following retired directories and files into a backup folder OUTSIDE the website root before extracting the overlay. Do not delete the backup. Extract this ZIP into its ROOT, where index.html and assets/ already exist. Choose replace/overwrite for matching files. Do not delete existing CSS, images, prayer guides or other files. This is an overlay, not a complete website archive.

Retired locale directories (move the entire directories): bn/, fa/, hi/, it/, nl/, cy/, sw/, ha/, so/, am/, yo/.
Retired translation files: translations/bn.json, translations/fa.json, translations/hi.json, translations/it.json, translations/nl.json, translations/cy.json, translations/sw.json, translations/ha.json, translations/so.json, translations/am.json, translations/yo.json.
Do not move the original 11 locale files, shared assets, prayer guides or legal pages. A fresh installation from this repository does not require this migration step.

Includes nine legal pages, language runtime, 11 dictionaries (283 strings each), 10 locale entry routes, translation notices, support and developer-support text. Sadaqah Jariyah and regional Spanish/Portuguese variants are not included.

Six automated localization tests passed. Run node --test tests/localization.test.cjs. Review the website locally before deployment. No mobile-app files are included. Language/legal certification is not implied.
